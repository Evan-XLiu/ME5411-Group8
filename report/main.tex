\begin{abstract}
This report presents an image-processing and machine-learning pipeline for
recognizing characters printed on a microchip. The report describes
the preprocessing, segmentation, feature extraction, classification, and
evaluation procedures developed by Group 8.
\end{abstract}

\paragraph{Keywords}
robot vision, image processing, character recognition, convolutional neural
network, classification


\section{Introduction}
Character recognition in low-contrast industrial imagery requires careful
preprocessing, segmentation, and classification. Classical image-processing
methods provide interpretable tools for enhancing and isolating characters
\cite{gonzalez2018digital}, while convolutional neural networks can learn
features directly from image data \cite{lecun1998gradient}.

The report follows the seven course tasks. Modules \texttt{task\_01}
through \texttt{task\_06} implement image processing;
\texttt{task\_07} contains the CNN and non-CNN classifiers.

\section{Problem Formulation}
The input is a 990-by-367 grayscale microchip image. The target line is
HD44780A00. Seven character classes (0, 4, 7, 8, A, D, H) are learned
from the separate course classification dataset. A stratified 75/25
training/test split is fixed with seed 42. Configuration selection uses
only a validation subset of the training data. Chip crops are used for
inference only, never training. The official input filename differs between
the assignment PDF and the local dataset; the group must confirm provenance.

\section{Methodology}

\subsection{Tasks 1--6: Integrated Image Processing}
Task 1 uses grayscale conversion, 1st--99th percentile contrast stretching,
CDF-based histogram equalization and mean-centered contrast scaling.
Task 2 compares normalized averaging filters of sizes 3, 5 and 7; the
5-by-5 mean output is passed downstream. Task 3 crops
$(x,y,w,h)=(45,180,930,180)$. Task 4 compares global Otsu and adaptive
Gaussian thresholding (block size 31, constant $C=-5$). The Otsu mask
is selected for subsequent processing.

Task 5 removes connected components with area below 200 pixels. Sobel
gradient magnitude on the smoothed ROI is normalized and thresholded
with Otsu, then masked to a dilated foreground neighborhood. An additional
binary outline is obtained by subtracting a 3-by-3 erosion from the cleaned
mask. Task 6 splits wide connected components at vertical-projection
valleys, using median component width to estimate the number of characters.
Ten boxes are expected for this specific target line. The known target
text supplies manual reference labels only; it is not a recognition result.

\subsection{Classifier}

\subsubsection{Subtask 7-1: CNN Classifier}

Subtask 7-1 employs a convolutional neural network (CNN) to classify the
segmented character images. The model distinguishes seven character
classes: 0, 4, 7, 8, A, D, and H.

Before being passed to the network, each character image is converted
to a single-channel grayscale image and resized to $32\times32$ pixels
using nearest-neighbour interpolation. The pixel intensities are then
scaled from $[0,255]$ to $[0,1]$. Let $I_r(u,v)$ denote the resized
grayscale image. The normalized input is defined as

\begin{equation}
I_n(u,v)=\frac{I_r(u,v)}{255}.
\label{eq:cnn_normalization}
\end{equation}

The feature-extraction stage contains three convolutional layers with
$3\times3$ kernels. The first convolutional layer converts the
single-channel input into 16 feature channels and is followed by batch
normalization, a rectified linear unit (ReLU), and $2\times2$ max
pooling. The second convolutional layer increases the number of
channels to 32 and applies the same batch-normalization, ReLU, and
max-pooling operations. The third convolutional layer produces 64
feature channels and is followed by ReLU activation and adaptive
average pooling, which reduces the feature maps to $4\times4$.

The ReLU activation function is defined as

\begin{equation}
\operatorname{ReLU}(z)=\max(0,z).
\label{eq:relu}
\end{equation}

The dimensions of the feature tensors throughout the network are

\begin{equation}
1\times32\times32
\rightarrow
16\times16\times16
\rightarrow
32\times8\times8
\rightarrow
64\times4\times4.
\label{eq:cnn_dimensions}
\end{equation}

The pooled feature maps are flattened into a feature vector containing

\begin{equation}
64\times4\times4=1024
\label{eq:flattened_features}
\end{equation}
elements. This vector is passed through a dropout layer with a
probability of 0.25 to reduce excessive dependence on individual
features. It is then processed by a fully connected layer containing
64 neurons and a ReLU activation. The final output layer contains
seven neurons corresponding to the seven character classes. The
classification stage can therefore be summarized as

\begin{equation}
1024\rightarrow64\rightarrow7.
\label{eq:cnn_classifier_dimensions}
\end{equation}

Let $z_{i,c}$ denote the output score produced for class $c$ for the
$i$th input sample. The corresponding class probability is calculated
using the Softmax function:

\begin{equation}
p_{i,c}
=
\frac{\exp(z_{i,c})}
{\displaystyle\sum_{j=1}^{K}\exp(z_{i,j})},
\label{eq:softmax}
\end{equation}
where $K=7$ is the total number of classes. The network is trained using
the multiclass cross-entropy loss

\begin{equation}
\mathcal{L}
=
-\frac{1}{N}
\sum_{i=1}^{N}
\log p_{i,y_i},
\label{eq:cross_entropy}
\end{equation}
where $N$ is the number of samples in a training batch, $y_i$ is the
ground-truth class of the $i$th sample, and $p_{i,y_i}$ is the
probability assigned to that class. The Adam optimizer is used to
update the network parameters according to the gradients of the
cross-entropy loss.

The dataset split, number of training epochs, batch size, learning
rate, random seed, and software and hardware environments are
described in the Experimental Setup section. Classification accuracy,
training time, and error analysis are presented in the Results and
Discussion sections.

\paragraph{Alternative CNN from the YJN branch}
The integrated code also provides a second architecture selected with
\texttt{--architecture yjn}. It uses three convolutional blocks with
16, 32, and 64 channels, each with batch normalization, ReLU, and
max pooling. Global average pooling produces 64 features, followed by
dropout with probability 0.3 and a direct classification layer.
Both architectures use the same input resizing and stratified 75/25
training/test split through the shared training interface. The
\texttt{baseline} option retains the architecture described above.
Measured comparisons and configuration-selection results are reported below.
Interpretation and recommendations remain subject to group review.

\subsubsection{Subtask 7-2: Non-CNN Classifier}
Subtask 7-2 uses a 32-by-32 unsigned-gradient HOG descriptor (4-pixel cells and nine
orientation bins). An RBF SVM with $C$ selected on validation data is used when scikit-learn is present;
the same interface falls back to a nearest-centroid classifier for a minimal
installation. The feature extractor, split seed, classifier type, and accuracy
are serialized so that the baseline can be compared with the CNN without
changing the data protocol.

\section*{Code Execution Guide}
Install Python 3.13 and the dependencies in \texttt{requirements.txt}.
Place the official classification folders and chip image under
\texttt{dataset\_2026/}. From the repository root run:
\begin{verbatim}
python segment.py
python scripts/run_experiments.py --epochs 20
python scripts/predict_characters.py \
  --model results/models/baseline_final.pt
python scripts/predict_characters.py \
  --model results/models/hog_svm_final.pkl
python scripts/build_report_results.py
python scripts/enrich_report.py
python -m pytest -q
make pdf
\end{verbatim}
The chip crops in \path{results/figures/characters/} are inference
inputs only. They must not be inserted into the classifier training dataset.
See the repository README for environment setup, input provenance,
validation protocol and timing boundaries. Model checkpoints are generated
locally by the experiment command.

# Course task modules

- task_01/enhance.py: enhancement comparisons.
- task_02/smooth.py: 3/5/7 averaging comparisons.
- task_03/crop.py: target-line ROI.
- task_04/binarize.py: Otsu / adaptive Gaussian.
- task_05/outline.py: cleanup and outlines.
- task_06/segment.py: component/projection segmentation.
- task_07/cnn.py and classical.py: classifiers.

Run `python segment.py` and `python scripts/run_experiments.py` from the
repository root. Full setup and prediction commands are in the root README.
Legacy classifier module paths remain compatible; legacy_pipeline contains
reference copies only.
